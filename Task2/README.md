# 🗄️ Task 2: SQL Data Analysis using MySQL

## 📌 Overview

This project is the **Week 2 assignment** of the **Data Analyst Internship by Skill Nexis**. The objective was to analyze a sales dataset using **SQL** in **MySQL Workbench** and extract meaningful business insights through queries.

The project focuses on developing a strong foundation in SQL by working with real-world sales data and applying various SQL concepts such as filtering, aggregation, grouping, sorting, conditional logic, and subqueries.

---

## 🎯 Objectives

* Import a CSV dataset into MySQL Workbench.
* Create and manage a relational database.
* Perform business data analysis using SQL.
* Generate insights from sales data.
* Practice industry-standard SQL queries.
